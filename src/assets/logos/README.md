# Company Logos

Add your company logos to this folder.

## Naming Convention

To keep things consistent and easy to load dynamically, please use the following format:

- **Format**: `lowercase-company-name.extension`
- **Preferred Extension**: `.svg` (for crisp vector rendering) or `.png` (with transparent background).
- **Examples**:
  - `netflix.svg`
  - `google.svg`
  - `riot-games.svg`
  - `pivotal-labs.svg`
  - `ibm-strategy.svg`

## Current Components

The site currently uses styled letter avatars as fallbacks. Once you add images here, we can update the code to load these images instead of the letters!
